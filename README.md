\# Experiment 1: Object Detection and Recognition





1\. Project Goal



Train a object detection model  and deploy it to Jetson Orin Nano.





2\. Target Requirements



\- Detect at least 2 object

\- Accuracy >= 80% on 20 test objects

\- Jetson inference speed >= 5 FPS

\- Publish detection results using ROS2

\- Save test results and representative failure cases
